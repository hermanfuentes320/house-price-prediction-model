The goal of this project is to establish a solid methodological basis for developing and validating a house price prediction model.

The analysis focuses not only on the final prediction accuracy, but also on understanding and justifying the decisions made throughout the modeling process, including:

✓ Why certain features were removed. 
✓ Whether missing values were handled using appropriate practices. 
✓ Whether the selected imputation techniques were suitable for the data. 
✓ Whether categorical variables were encoded appropriately. 
✓ Whether the selected combination of features provides the best predictive performance. 
✓ Whether the chosen model is appropriate for the problem. Whether the selected hyperparameters are optimal. 
✓ Whether the final model generalizes well to unseen data.

The objective is therefore to ensure that the final model is not only accurate, but also supported by a structured and justifiable data preparation, feature selection, model selection, and hyperparameter optimization process.
